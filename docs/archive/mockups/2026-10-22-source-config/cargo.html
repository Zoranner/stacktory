Cargo

地址
https://pkg.rd.kim/mirror/cargo/group/

提示词

请把本机 Cargo 的 crates.io 源切换到 Stacktory。

目标地址：https://pkg.rd.kim/mirror/cargo/group/
要求：
1. 先读取 ~/.cargo/config.toml，确认当前格式并保留无关配置；
2. 修改前备份原文件，并在结果中报告备份路径；
3. 只修改 crates.io 的 source replacement，不删除其他 source；
4. 保持幂等，重复执行不要重复追加配置；
5. 修改后执行 cargo fetch 验证；
6. 输出实际修改的文件、备份路径和验证结果；
7. 如果路径、权限或配置格式不确定，停止并报告，不要猜测。

配置

~/.cargo/config.toml 
[source.crates-io]
replace-with = "stacktory"

[source.stacktory]
registry = "sparse+https://pkg.rd.kim/mirror/cargo/group/"
